## 1. 记录规则

1. 每天工作结束前由当日负责人填写“实际完成、遗留问题、证据链接和次日安排”。
2. 完成状态只允许使用：`未开始`、`进行中`、`已完成`、`受阻`、`取消`。
3. “已完成”必须有可核查证据，例如代码提交、图纸、照片、测试记录、采购单号或会议纪要。
4. 发生接口、范围、安全或交期变化时，当天补充变更记录，不允许只在群聊中口头确认。
5. 每周由车晨星汇总进度；胡雨皓核对完成证据；相关模块负责人确认技术内容。
6. 不在仓库中提交账号密码、Wi-Fi 密码、气体供应商账户、个人隐私或大体积原始视频。
7. 模型版本按连续整数递增；同一自然日只发布并记录当天最终确认的最新一版。当天中间试验文件可保留本地追溯，但不单独写入实施日志或作为正式交付版本。
8. 每次推送 GitHub 前必须更新本日志；同一自然日的新增内容合并追加到同一个日期条目，不新建重复日期记录。推送前须核对日志已包含实际完成、可核查证据、风险/变更和下一步。
