# 双节点台架外部传感器接线冻结（2026-09-27）

本表冻结当前**台架实物接线约定**，依据用户确认“外部传感器全都接好”、MQ2-02 的 DO→Node A PB13、Node A PC10→风机 01 三极管基极，以及此前四路液位逐路实测。冻结的是接线与资产编号，不把用户的接线确认当作全部通道的电压、标定、断线和报警验收。改线须同步更新此表、固件引脚表和测试记录。

Node A 为 CTRL-01 / COM5；Node B 为 CTRL-02 / COM3。Node A 20 路、Node B 11 路外部传感器已接；LEVEL-05 实物已拆除，固件保持禁用。两块 INA226 另列于下文，不计入上述 31 路。

| 类别 | 资产编号 → 节点引脚 | 接入信号 |
| --- | --- | --- |
| 温湿度 | SHT-01/02 → A PB6 SCL、PB7 SDA；SHT-03/04 → A PB10 SCL、PB11 SDA | 软件 I²C；同总线地址分别 0x44/0x45 |
| 一氧化碳 / MQ-7 | CO-01 → A PC1；CO-02 → A PA0；CO-03 → A PB1；CO-04 → B PB0；CO-05 → B PB1 | AO → ADC |
| 甲烷 / MQ-4 | MQ4-01 → A PC2；MQ4-02 → A PA4；MQ4-03 → B PA0；MQ4-04 → B PA1；MQ4-05 → B PA4 | AO → ADC |
| 氧气 AO-02 | O2-01 → A PC3；O2-02 → A PA5；O2-03 → B PA6 | AO-02 电极 → 各自低电压放大调理电路 → ADC；不可直接接 ADC |
| 烟雾 / MQ-2 | MQ2-01 → A PB12；**MQ2-02 → A PB13**；MQ2-03 → A PC11；MQ2-04 → B PC8；MQ2-05 → B PC9 | DO → GPIO；AO 不接 |
| 火焰 | FLAME-01 → A PB14；FLAME-02 → A PC8；FLAME-03 → A PC9；FLAME-04 → B PC6；FLAME-05 → B PC7 | DO → GPIO |
| 液位 | LEVEL-01 → A PC0；LEVEL-02 → A PC12；LEVEL-03 → A PC13；LEVEL-04 → B PC10 | DO → GPIO；四路干湿状态已有 MQTT 实测记录 |
| 已拆除 | LEVEL-05 → B PC11（预留、未接实物） | 固件禁用，不应显示为在线 |

INA226-FAN1 与 SHT-01/02 共用 A PB6/PB7，INA226-FAN2 与 SHT-03/04 共用 A PB10/PB11。INA226 的风机电源测量端保持现有线路；本次不改动。

Node A 的 **PC10 接风机 01 三极管基极，不再分配给传感器**。用户确认风机 01 可以调速；当前源码的实际 PWM 输出为 PB8 / TIM4_CH3，PC10 配为输入。因此 PB8 至基极的实物导通路径尚待断电核对，但不得因此把 PC10 重配置为传感器输入或改动现有风机接线。Node B PC10 独立属于 LEVEL-04，与 Node A PC10 不冲突。

MQ 模块的加热电源使用独立 5 V 供电并与对应 MCU 共地。MQ-4、MQ-7 的 AO 与氧气调理电路输出在 MCU 引脚侧必须处于 0～3.3 V；MQ-2、液位等 5 V 模块的 DO 需经已确认的电平转换或分压后进入 STM32。**是否已装调理电路及引脚侧最大电压，本次未收到逐路实测值，不能记为已验收。** 新启用通道只采样和上报；标定与报警授权另行验收。

### AO-02 氧气传感器实物更正（2026-09-27）

用户提供的 AO-02 底部接口图标明 Molex 三针：1 为传感器正极，2、3 为传感器负极。厂家手册确认传感器本体**不需要外部电源**，空气中的差分输出只有约 9～13 mV，外部负载电阻须不小于 10 kΩ。此前把它当成“5 V 供电、AO 输出”的三针模块的说法不适用；绝不能把 5 V 或 3.3 V 接到任一传感器电极，也不能将毫伏级电极输出当成已调理的 AO 直接接 STM32。三个实物编号仍分别对应 A PC3、A PA5、B PA6，但这些 ADC 引脚应接各自**低失调、高输入阻抗放大调理电路的输出**，输出范围在实测和设计上都不得超过 0～3.3 V。2、3 均标为负极，线束插座背面观察时左右镜像，须按插针编号而非线色辨认。调理板型号、增益、供电及三路引脚侧实测值尚未确认，故本表不宣称 AO-02 已完成电气接入。原厂依据：[AO-02 数据手册](https://www.aosong.com/userfiles/files/media/AO-02%20Datasheet%20%20A2-20240131.pdf)。

Node A 屏幕按传感器类别将两块板的数据放在同一页。显示 Node B 实时值依赖 CTRL-02 的 ESP 发布遥测，以及新版 CTRL-01 ESP 订阅并转发至 Node A；只更新两块 STM32 时，Node B 数据仍可能显示离线。软件映射见 `firmware/stm32f103rct6/Core/Inc/node_sensor_pin_map.h`，四路液位证据见 `docs/acceptance/2026-09-26-四路液位台架接入记录.md`。
