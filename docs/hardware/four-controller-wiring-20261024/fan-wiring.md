# 两台排风机重新规划 V0.2

> **已由2026-10-26 V0.3替代：** 当前新编号、双屏与就近引脚见[最新完整接线表](../four-controller-wiring-20261026/README.md)。本目录保留历史归属与引脚作迁移依据，不能混用两个版本施工。

日期：2026-10-24。对应四主控接线规划V0.2。本表是新接线目标，未执行实物改线、烧录或测试。

## 安装和职责

- FAN-01靠左上CTRL-01一侧外壁，FAN-02靠右下CTRL-04一侧外壁，均向箱体外排风；位置避开屏幕、麦克风和检修口。
- 补风口与排风口错开，避免只在邻近小区域形成气流短路；两个区域应能从外界补入空气。用无危险气源的气流观察检查中央P5有无明显死区，不凭示意位置宣称换气量达标。
- 风机抽取管廊内部空间空气，业务管子的两进两出保持原布局，不与排风机串接。
- 继电器负责供电通断，PWM负责调速，TACH反馈转速，INA226反馈负载电流/电压。四项分别记录，不用“命令已下发”代替实际转动。

## 统一引脚

| 信号 | FAN-01 / CTRL-01 | FAN-02 / CTRL-04 | 接入对象 |
| --- | --- | --- | --- |
| 调速输出 | PB8 / TIM4_CH3 | PB8 / TIM4_CH3 | 独立驱动输入→风机PWM |
| 转速反馈 | PA7 / EXTI7 | PA7 / EXTI7 | 确认为3.3V兼容后接入的TACH信号 |
| 电源继电器 | PA1 | PA1 | 现有驱动IN1 / IN2 |
| INA226 SCL | PB6 | PB10 | 所属本地软件I²C |
| INA226 SDA | PB7 | PB11 | 所属本地软件I²C |
| INA226地址 | 0x40 | 0x40 | 两板各自独立，无地址冲突 |

同名PB8、PA7、PA1位于不同MCU，不互相短接。CTRL-01原PA6测速改到PA7；风机2原CTRL-01 PB9/PWM、PA7/TACH、PA15/继电器控制整组迁出，在CTRL-04改用PB8/PA7/PA1。CTRL-01 PC10旧基极线拆离，不接新输出。

## 每台风机的功能接线

```text
12V分支 ─ 保护 ─ 继电器COM/NO ─ INA226高侧分流通路 ─ FAN +12V
电源负极/本区负载回线 ─────────────────────────────── FAN GND

所属STM32 PB8 ─ 原兼容驱动输入 ─ 开集电极/开漏输出 ─ FAN PWM
所属STM32 PA7 ← 3.3V兼容的测速信号 ←─────────────── FAN TACH
所属STM32 PA1 ─ 已验证的继电器驱动输入(IN1或IN2)

所属STM32 3.3V ─ INA226逻辑VCC
所属STM32 本地SCL/SDA ─ INA226 SCL/SDA
INA226测量端/风机负极/驱动地 ─ 按原理图接本区确定的参考与回流
```

图中的+12V/GND/PWM/TACH是功能名，不能当作现有风机插头的从左到右顺序；颜色和端子顺序按风机实物定义。继电器触点COM/NO与线圈供电/IN控制完全分开。INA226的IN+/IN−、VBUS按现有模块核对，逻辑VCC不接12V。

## 驱动与状态

- 复用现有兼容的PWM驱动，每台驱动输入只接所属PB8，地接本区参考；旧控制线先断开再接新线。开集电极/开漏接口以实际25kHz波形、高低电平和上升时间合格为条件，不凭拓扑保证稳定。驱动器若反相，软件需换算风机端占空比。
- PWM初始目标25kHz，最终以实际B12风机能力为准；不能把PWM脚接12V，也不用继电器触点做高速调速。
- 若TACH确认为开集电极，使用到3.3V的合适上拉；若原模块已有高电压上拉，先处理该上拉，不能叠加后直接接PA7。每转脉冲数沿旧值2作为待确认参数，不将其他品牌规格当作B12已验证值。
- 初始化时PA1与外部偏置保持继电器不吸合，软件完成PWM配置后才允许接通风机电源。对普通启停提供最短切换间隔，避免继电器抖动；具体时长在联调时冻结。
- 启动后给实际加速时间，再判断TACH与电流；停机通过继电器断开供电，并允许转子惯性滑行。不能要求断电瞬间RPM立刻为0。
- 网关掉线后，各风机由所属节点本地状态机处理，不由超时盲目清零。CTRL-01/04只能直接处理各自连接的现场信息；P3/P5跨板排风仍依赖网关。停机、保持、报警全速等具体故障策略在固件状态表另行冻结，本表不擅自新增阈值。
- 复位默认断开是本次台架控制约定，不是已完成风险评估的“故障时持续排风”设计。

## 断电迁移顺序

1. 标记FAN-01/FAN-02和所有旧线，拆开旧主控的PWM、TACH、继电器控制线；旧PC10、PB9、PA15等不与新输出并接。
2. 分别将两路驱动输入接所属板PB8、测速接所属板PA7、继电器输入接所属板PA1。若沿用一块双路继电器PCB，保留整块板，只分开IN1/IN2控制。
3. 保留两个独立12V触点/INA负载支路，不将两个INA分流通路串接；核对极性、共地、逻辑供电和关机断电状态。
4. 用新固件先测试一台，再测试第二台，最后两台同时运行。旧两节点镜像与新针脚不同，不能直接沿用。

## 现场验收项

| 操作 | 应观察的证据 |
| --- | --- |
| 上电、复位、下载程序 | 继电器无误吸合，默认输出与约定一致 |
| 分别启停FAN-01/02 | 只对应的风机动作，继电器/转速/电流身份一致 |
| 多档调速 | 风机端PWM波形与转速变化一致，反相已处理 |
| 正常停机 | 断电后电流下降、RPM随惯性衰减；状态不冒充立即停止 |
| 拔测速线或断开风机电源 | 能区分反馈缺失、无供电及命令未执行，不强行显示运行 |
| 断开485/网关 | 所属板继续执行已定义本地策略，跨区能力如实降级 |
| 双风机＋灯带＋语音同时运行 | 主控/ESP无掉电复位，485与ADC无明显异常 |
