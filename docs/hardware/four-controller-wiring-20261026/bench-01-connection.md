# 首轮台架：S3网关与4号板

日期：2026-10-26。范围：只接一主一从的低压485通信，不接屏幕、传感器、风机、继电器或灯带。接线、终端和新固件通过后再扩展。

## 本轮照片所能确认的事项

- STM32样板：照片芯片丝印为STM32F103RCT6；可见PA2/PA3、3V3/GND排针及USB通信/ISP下载接口。只确认照片中的这一块，不能由此认定另外三块板卡版本完全一致，也不能由照片确定它已贴4号标签。
- S3样板：模块罩标记S3-N16R8；GPIO17/18确已引出，位于照片左排16与8之间，板有UART和USB两个Type-C接口。容量、厂家板型、上电识别尚未验证；不把第三方板认作官方DevKitC原板。
- 485样板：背面为鹿小班485通信模块；正面五针依次可见3V3/GND/TXD/RXD/NC，三位端子从照片左到右A/B/GND。形态和接口与既有选定模块方案对应；芯片具体型号、开关导通方向和板载终端阻值未从照片证明。
- 所有照片均不证明供电电压、自动收发时序、已接通通信或实物功能验收。

## 两端TTL接线

先给照片中的STM32贴“4号/CTRL-04”，给两个模块分别贴“4号485”和“网关485”。两板断电并断开旧PA2/PA3通信线后操作。

S3照片中的排针孔看起来尚未安装排针；若实物确实未焊接，先焊好所需排针或可靠焊线，再连接杜邦线，不能将杜邦线插入裸通孔当作可靠连接。

| 模块五针 | 4号485 → STM32 | 网关485 → S3 |
| --- | --- | --- |
| 3V3 | 本板3V3 | S3的3V3 |
| GND | 本板GND | S3的GND |
| TXD | PA2（USART2_TX） | 17（UART TX） |
| RXD | PA3（USART2_RX） | 18（UART RX） |
| NC | 不接 | 不接 |

TXD/RXD采用此前针对所选模块已核对的命名：MCU发送接模块TXD，MCU接收接模块RXD；不能作为所有TTL串口模块通用规则。S3板顶端另标TX/RX的引脚不接本485，它们是下载/日志串口资源。

S3 GPIO17/U1TXD与GPIO18/U1RXD可由[Espressif引脚资料](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.0.html#header-block)核对；以照片实物17/18丝印定位，不数排针序号。

## 模块间三根线

```text
网关485端子             4号485端子
     A ─────────────── A
     B ─────────────── B
   GND ─────────────── GND
```

A/B同一双绞对，另一根为非隔离台架信号参考地。模块排针GND和总线GND属于各自模块同一参考网络，不将A/B接进STM32 GPIO。两板3V3、5V输出不互接，各板只给自己的485模块供电。

## 本轮终端与供电

本轮仅网关和4号，故两个模块都是物理端点，需要启用两端终端。不能套用完整四板网络中“4号终端关闭”的状态。后续扩展为网关→4→3→2→1时，4号终端关闭，1号末端启用。

开关位置在本轮照片中没有可读的ON/120Ω方向说明，不能凭滑块向上/向下猜测。可先断电、模块彼此分离并隔离A/B外接线，用万用表比较开关两个位置的A-B电阻；若其中一档稳定约120Ω、另一档明显较高，则前者为该板的终端接入档。若读数不符合这个规律，再核对商品原理图，不盲目把它认作120Ω开关。

接好后先保存接线照片并复核，再配合最小新固件上电。S3使用丝印UART的Type-C作为初次下载/日志口，STM32按既有习惯用ISP下载USB；各板首次单独枚举识别，避免把COM编号当作设备身份。不能用灯亮、USB已识别或旧固件主动发JSON当作485请求/应答测试通过。

## 当前状态

最初照片核对及接线指引已完成。后续用户报告接线完成，并确认COM5只连接4号STM32。已完成[独立最小诊断固件](../../../firmware/rs485-bench/README.md)两端构建，4号板256KB原Flash备份、写入校验及独立读回一致，真机启动协议自检通过、运行时间推进且错误计数为0。S3尚未接入电脑烧录，requests仍为0；终端实际阻值和485端到端通信未验证。当前下一步为用户恢复4号BOOT0/BOOT1为0并复位，再连接S3的UART口；不将单板烧录/自检当作485联调通过。

同日最新进展：用户接入S3的COM口，实际为COM3/CH343；已实读容量、完整备份16MB Flash、烧录并独立读回四段镜像一致。S3与4号板已经收发：首轮采集35条连续合法回复且CRC为0，S3工具RTS复位后再采集12条合法回复。两节点短时通信与S3复位恢复通过，详见诊断固件说明和验收JSON。UART历史累计为674、S3读回/复位窗口后675，正常捕获期间均无新增；实体断线、终端阻值、STM32冷启动及四节点测试仍未执行。
