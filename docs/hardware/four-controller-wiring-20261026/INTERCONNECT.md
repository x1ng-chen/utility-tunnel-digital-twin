# 四主控之间的全部通信线路

2026-10-26。施工目标，尚未确认四板全部接完/通电/通信。先全部断电接线，1/2号刷入正确地址固件、网关更新后再逐段测试。

四块STM32各配一个已选3.3V自动收发485模块，S3网关再配一个，共5个。MCU之间不直接接TX/RX或其他GPIO。编号以用户俯视图为准：左下1、右下2、右上3、左上4。

| 每块STM32 | 接自己485模块的黄色排针 |
| --- | --- |
| 3V3 | 3V3 |
| GND | GND |
| PA2 / TX | TXD |
| PA3 / RX | RXD |
| 不接 | NC留空 |

| S3网关 | 接网关485模块的黄色排针 |
| --- | --- |
| 3V3 | 3V3 |
| GND | GND |
| GPIO17 / TX | TXD |
| GPIO18 / RX | RXD |
| 不接 | NC留空 |

TXD/RXD同名接法只针对项目所选、已核对命名的模块，不套用未知TTL转换模块。S3用标17/18的脚，不用顶部下载串口TX/RX。

五模块之间连接绿色螺丝端子，路径沿外围而不闭合：

```text
网关485       4号485       3号485       2号485       1号485
   A ────────── A ────────── A ────────── A ────────── A
   B ────────── B ────────── B ────────── B ────────── B
 GND ──────── GND ──────── GND ──────── GND ──────── GND
```

一共4段三线主干：网关→4、4→3、3→2、2→1，每段均A接A、B接B、GND接GND。4/3/2号的同名端子分别夹紧前后两段线；端子不适合夹两线时用合适的短接分线端子，不留松动裸线。A/B用同一对双绞线；不从网关向四板分四条长支路，也不把1号再接回4号/网关。

| 完整五模块主干 | 120Ω终端 |
| --- | --- |
| 网关 | 接入 |
| 4号 | 退出 |
| 3号 | 退出 |
| 2号 | 退出 |
| 1号 | 接入 |

开/关指是否接入120Ω，不代表已确认滑块朝向。原理图或断电隔离测量确认档位：单模块A-B一档约120Ω且另一档明显更高时，前者才可认作终端接入档。测量不符合则继续核对，不猜方向。单网关＋4号时终端在网关/4号；加3号变为网关/3号；最终五模块才是网关/1号。

各板只给自己的485模块供电；不同主控的3V3、5V输出不互连。非隔离低压台架共参考地，风机/MQ/灯带负载回流不用细通信地。原ESP8266占用PA2/PA3的线须先断开。传感器、屏幕、摇杆、风机等按[本地引脚表](README.md)就近接入，不为显示或菜单把远端GPIO跨区拉线。
