# 双屏与摇杆接线

> **2026-09-24 台架状态更新：** 本文中的屏幕、摇杆、ESP 引脚约定继续有效；第 5 节风机继电器和 INA226 总线的旧说明已过时。完整当前引脚以 [双节点最新接线与传感器引脚规划](2026-09-24-双节点最新接线与传感器引脚规划.md) 为准：Node A PA1/PA15 分别控制两路继电器，INA226-FAN1/FAN2 分别在 PB6/PB7 与 PB10/PB11。

> 版本：V1.0（2026-09-14）
> 依据：固件源码 `firmware/stm32f103rct6/`（提交 `153cae0`）与设计规格
> `docs/superpowers/specs/2026-09-11-dual-screen-joystick-menu-design.md`。
> 本文是两块 ST7735S 屏、五针摇杆和两路 ESP8266 的**权威引脚约定**；
> 表中的引脚由固件宏定义与持久化契约测试直接导出，不是计划阶段的手绘表。
>
> **实物状态：全部接线均为待验证。** 本表描述的是固件要求的接线目标，
> 不是已经测量过的实物。任何未在实物上通电观察过的项目在本文和
> `docs/acceptance/双屏菜单实机验收.md` 中一律保持“未完成”。

## 1. 两台设备的角色

| 节点 | 设备 ID | ESP8266 | 屏幕角色 | 摇杆 |
|---|---|---|---|---|
| Node A | `CTRL-01` | ESP-01（`esp01_ctrl01`） | 只读状态副屏，5 秒自动轮播，报警时接管 | 不接 |
| Node B | `CTRL-02` | ESP-02（`esp01_ctrl02`） | 唯一交互主屏，菜单与设备控制 | 五针模拟摇杆 |

Node A 只采集、执行安全联动、给出执行回执；Node B 只做交互和显示。
Node A 的副屏**不接受摇杆输入、不解析 MQTT、不驱动任何执行器**。

## 2. 屏幕引脚

两块屏都是 1.44 寸 ST7735S（128×128、RGB565、仅写 SPI、不用 MISO）。

### 2.1 Node A / CTRL-01 副屏（SPI3 + DMA2 Channel 2）

| 屏幕丝印 | Node A STM32 | 说明 |
|---|---|---|
| `GND` | `GND` | 与 Node A 共地 |
| `VCC` | `3.3V` | 不得接 5 V |
| `SCL` | `PB3 / SPI3_SCK` | SPI3 默认引脚，无需 AFIO 重映射 |
| `SDA` | `PB5 / SPI3_MOSI` | 仅 MOSI，不用 MISO |
| `RES` | `PC4` | 复位 |
| `DC` | `PC5` | 数据/命令选择 |
| `CS` | `PC6` | 片选 |
| `BLK` | `PC7` | 背光 |

**为什么控制线落在 GPIOC**：Node A 的 `PB6/PB7` 是 SHT30 软件 I²C、`PA7` 是
风机 2 转速反馈、`PB8/PB9` 是 `TIM4_CH3/CH4` 两路风机 PWM。`PB8=CS`,
`PB9=BLK` 的早期计划映射会直接夺走两台风机调速，已废弃；权威约定固定为
`PC6=CS`、`PC7=BLK`。

**`PB3` 与 JTAG**：`PB3` 是 `JTDO`。两块板**共用**的
`Core/Src/stm32f1xx_hal_msp.c::HAL_MspInit()` **无条件**调用
`__HAL_AFIO_REMAP_SWJ_NOJTAG()`（`stm32f1xx_hal_msp.c:83`），
因此 Node A 与 Node B 的 JTAG 都被关闭、SWD（`PA13/PA14`）都保留。
Node A 借此把 `PB3` 用作 SPI3_SCK；Node B 的 `PA15/PB3/PB4` 也因此一并
释放（当前固件未使用）。两块板都仍可用 ST-Link 调试与烧录。

### 2.2 Node B / CTRL-02 主屏（SPI1 + DMA1 Channel 3）

| 屏幕丝印 | Node B STM32 | 说明 |
|---|---|---|
| `GND` | `GND` | 与 Node B 共地 |
| `VCC` | `3.3V` | 不得接 5 V |
| `SCL` | `PA5 / SPI1_SCK` | SPI1 默认引脚 |
| `SDA` | `PA7 / SPI1_MOSI` | 仅 MOSI |
| `RES` | `PB6` | 复位 |
| `DC` | `PB7` | 数据/命令选择 |
| `CS` | `PB8` | 片选 |
| `BLK` | `PB9` | 背光 |

`PA6`（SPI1_MISO）**不连接**。Node B 没有 SHT30/TIM4 风机占用，
所以仍沿用开发板 LCD 排针原有的 `PB6—PB9` 控制线，只把时钟与数据改到 SPI1。

> **引脚号相同、板子不同**：`PC4` 在 Node A 是屏幕 `RES`，在 Node B 是摇杆
> `SW`；`PC0/PC1` 在 Node A 是气体 ADC，在 Node B 是摇杆轴。两块板子的
> 引脚表互相独立，接线时务必按“节点”而不是按“引脚号”对照。

## 3. 摇杆（仅 Node B）

五针模拟摇杆（模块丝印常见 `GND / +5V / VRx / VRy / SW`）。

| 摇杆引脚 | Node B STM32 | 用途 | 固件配置 |
|---|---|---|---|
| `GND` | `GND` | 公共地 | — |
| `+5V`（丝印） | **`3.3V`** | 供电 | **必须接 3.3 V** |
| `VRx` | `PC0 / ADC1_IN10` | 水平 | 12 位 ADC、239.5 周期采样、5 ms 采样周期 |
| `VRy` | `PC1 / ADC1_IN11` | 垂直 | 同上 |
| `SW` | `PC4` | 按下为低 | 内部上拉 `GPIO_PULLUP` |

> ⚠️ **供电警告**：模块丝印写的是 `+5V`，但**只能接 3.3 V**。摇杆电位器
> 是分压输出，`VRx`/`VRy` 直接进 STM32 ADC。若按丝印接 5 V，摇杆推到底
> 时 ADC 输入会接近 5 V，超过 3.3 V 绝对最大额定值，可能永久损坏
> `PC0/PC1`（甚至整片 MCU）。`SW` 是独立的机械触点，内部上拉已使能，
> 不需要外接上拉电阻。

固件侧的输入处理（均已由主机测试覆盖，**手感与漂移仍待实物验证**）：

| 参数 | 值 |
|---|---|
| 启动校准样本 | 16 次（要求上电时保持松手） |
| 中心死区 | ±500 ADC（默认中心 2048） |
| 迟滞 | 100 ADC |
| 按键消抖 | 25 ms |
| 长按阈值 | 1000 ms |
| 连续滚动延迟 / 周期 | 350 ms / 100 ms |

## 4. ESP8266 UART（Node A 与 Node B 相同）

| STM32 | ESP-01S | 说明 |
|---|---|---|
| `PA2 / USART2_TX` | `RX` | STM32 → ESP |
| `PA3 / USART2_RX` | `TX` | ESP → STM32 |
| `PA9 / USART1_TX` | USB-TTL RX | 调试/烧录串口 |
| `PA10 / USART1_RX` | USB-TTL TX | 调试/烧录串口 |

两块 ESP 均为 **9600 bit/s、8N1**，USART1 与 USART2 在 72 MHz 时钟下
分频误差为 0（`BRR=7500` / `BRR=3750`，由契约测试断言）。

ESP-01S 必须**独立稳定 3.3 V 供电**（建议 500 mA 以上余量），不得接 5 V；
EN/CH_PD 与 GPIO2 上拉 3.3 V，GPIO0 仅在上电瞬间拉低进入烧录模式。
所有设备共地。

## 5. Node A 现有接线（本次改造全部保留）

改造只新增 SPI3 屏幕的 6 根信号线，**没有改动下表任何一项**，
也没有回收 `PB8/PB9` 的风机 PWM。

| 功能 | 引脚 | 备注 |
|---|---|---|
| SHT30 槽位 1（I²C 总线 1） | `PB6=SCL`、`PB7=SDA`、地址 `0x44` | 软件 I²C |
| SHT30 槽位 2 / 3 | 同上总线与 `i2c2_bus = PB10/PB11`、地址 `0x44`/`0x45` | 软件 I²C |
| INA226 ×2（风机电压/电流） | `i2c2_bus = PB10/PB11` | 共享软件 I²C 总线 |
| 氧气 ADC | `PC3 / ADC1_IN13` | 未标定，仅遥测 |
| 甲烷 ADC | `PC2 / ADC1_IN12` | 唯一可驱动执行器（通风）的气体通道 |
| CO ADC | `PC1 / ADC1_IN11` | 未标定，仅遥测 |
| 烟雾数字量 | `PB12` | 低有效，4 次 50 ms 稳定采样后报警（无保持时间） |
| 火焰数字量 | `PB14` | 低电平触发，告警保持 12 s |
| 液位 L01（FS-IR02） | `PC0` | 5 V 板卡经分压，低有效 |
| 风机 1 TACH | `PA6` | 每转 2 脉冲 |
| 风机 1 PWM | `PB8 / TIM4_CH3` | 25 kHz |
| 风机 2 TACH | `PA7` | 每转 2 脉冲 |
| 风机 2 PWM | `PB9 / TIM4_CH4` | 25 kHz |
| 继电器总使能 | `PA1` | 高电平吸合 |
| 有源蜂鸣器 | `PB0` | 高电平鸣响 |
| WS2812 灯带 DIN | `PB15 / SPI2_MOSI` | 经 74AHCT 电平转换，4.5 MHz 编码 |
| ESP8266 | `PA2/PA3 / USART2` | 9600 8N1 |
| 调试串口 | `PA9/PA10 / USART1` | 9600 8N1 |
| SWD | `PA13/PA14` | **保留**；仅 JTAG 关闭，SWD 始终可用 |

Node A 的持久化契约测试会断言这 22 个引脚互不冲突
（`pins=22 buses=2 no-collisions`），并断言新屏幕引脚与该集合不相交；
`TIM4->CCR3/CCR4/ARR`、`DMA2_Channel1`、`DMA1_Channel5` 在屏幕适配器
运行后必须保持不变。

## 6. BOOT / 烧录接口保留

| 项目 | 状态 |
|---|---|
| `BOOT0` / `BOOT1` | 保持可跳线，串口 BootLoader 烧录路径不变（`0x08000000`） |
| SWD（`PA13/PA14`） | 两块板均保留，ST-Link 可随时连接 |
| JTAG（`PA15/PB3/PB4`） | **两块板均已关闭**：两节点共享的 `HAL_MspInit()` 无条件调用 `__HAL_AFIO_REMAP_SWJ_NOJTAG()`，SWD 保留 |
| USART1 | 两块板保持调试串口，不占用屏幕引脚 |

两块板关闭 JTAG 后 `PA15/PB4`（以及 Node B 的 `PB3`）也一并释放，但当前固件
未使用它们；不要把它们改接成屏幕控制线，Node A 的约定位置是 `PC4—PC7`。

## 7. 上电前检查（接线核对，不是性能验收）

1. 用万用表通断档确认所有模块共地，且屏幕 `VCC` 实测为 3.3 V。
2. 确认摇杆 `+5V` 丝印脚接的是 **3.3 V**，不是 5 V。
3. 确认 `PC6`（Node A `CS`）与 `PC7`（Node A `BLK`）没有接到 `PB8/PB9`。
4. 确认 `PB8/PB9` 仍接两台风机 PWM，未被屏幕占用。
5. 确认 Node A 的屏幕信号线未跨接到 `PB6/PB7`（SHT30）或 `PA7`（风机 2 TACH）。
6. 确认两块 ESP 由独立 3.3 V 供电，不取自 STM32 板载 3.3 V 大电流负载。

以上 6 项在实物上完成后，须在 `docs/acceptance/双屏菜单实机验收.md`
逐项签字；**本文不预先勾选任何一项**。
