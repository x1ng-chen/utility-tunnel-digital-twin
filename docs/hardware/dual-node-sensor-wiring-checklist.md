# 双节点多传感器接线与上电前核对清单

> **历史草案，请勿直接照本表接线。** 2026-09-24 起以 [双节点最新接线与传感器引脚规划](2026-09-24-双节点最新接线与传感器引脚规划.md) 为台架接线基准。本旧表将 SHT30 地址脚写成统一 `ADDR`、将部分未知 CO/O2/MQ4 模块预设为 5 V/≤3.3 V，且未列出当前 PA15 双继电器和 INA226 分总线状态；这些都必须以新表及实测为准。

本文档为双节点多传感器扩展方案（32 路传感器）在**物理接线与通电前**的必检清单。所有通道在未经实测电压与极性核验前，严禁直接连接 STM32 GPIO/ADC 输入引脚。

## 3. 上电与首次接入流程规范

1. **断开 STM32 信号线**：在各传感器初次上电时，断开通往 STM32 排针的信号连接跳线。
2. **量测模块供电与输出**：使用高精度数字万用表测量各模块 VCC、GND 电压，以及常态和触发状态下的输出电压（记录填入上表）。
3. **加装电平转换**：确认所有进入 STM32 的信号电压均稳定在 0～3.3 V 范围内后，方可连接至 MCU 引脚。
4. **逐路使能与验证**：按照规范顺序（SHT30 组 -> Node A 模拟 -> Node B 模拟 -> Node A 数字 -> Node B 数字）逐路在固件中启用通道，验证遥测资产编码与报警联动。
