# 三维告警高亮视觉增强（2026-10-29）

## 变更

- 对已绑定的具体告警设备增加双层缓慢扩散定位圈、轮廓框、垂直引线和白色定位点。模型本身不移动、不缩放。
- 严重告警使用红色，关注告警使用琥珀色；设备本体、定位圈与标牌使用一致等级。
- 屏幕标签显示工位、告警名称和具体设备编号，可点击定位。标签跟随模型投影并避让，视野外不伪造标记；底部摘要仍提供定位入口。
- 无告警时不显示边框和告警摘要；恢复后清除定位效果并按原材质基线恢复设备颜色。已确认但未恢复的告警继续保留。
- 模型未绑定或为空几何时，明确提示位置未绑定，并清除旧标签；不把预览占位物当成定位成功。
- 支持系统减少动态效果偏好；无需后处理辉光、额外照明或声音。

## 验证

- 前端全部测试：136通过、1跳过；类型检查及生产构建通过。末次修改后再次回归，结果见交付说明。
- 使用实际 `TwinScene.vue`、V20 GLB与隔离模拟输入，在浏览器检查P5单点、P3/P5双点、恢复正常及点击定位。
- 隔离预览位于私有 `.hardware-live/alarm-preview/`，仅监听本机5197端口，不调用业务API、不写业务库、不连接MQTT；截图及配置留在私有目录。
- 之前P5实物触发、实时推送和恢复的记录仍见 `flame-highlight-acceptance-20261028.md`。本次增强后的外观仅完成软件与隔离浏览器检查，尚未重新进行实物触发验收。

## 使用

重启前端或刷新“三维孪生”后生效。实际告警、恢复判断与自动定位开关沿用原逻辑，不新增控制指令或模拟业务数据。
