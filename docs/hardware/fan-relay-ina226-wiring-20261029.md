# 两台风机、继电器、INA226与PWM/TACH接线

依据2026-10-27 r2实际烧录记录及归档源码核对，2026-10-29用户再次确认：INA226为R010、继电器高电平触发、PWM经过原三极管驱动。
PWM负责调速，TACH负责测速；现有实现不等于自动维持目标RPM的闭环调速。

## 逐根接线速查：先分清继电器两侧

DC+、DC−是继电器模块供电；IN是主控控制输入。COM、NO、NC是继电器触点。
COM在这里表示公共触点，接12V风机电源正极，不是串口，也不是GND。
继电器释放时COM与NO断开，吸合后COM与NO导通；本项目用常开NO，NC留空。

**已查回原台架明确接法：5V→DC+，GND→DC−，跳帽置H。** 来源是本工程`hardware/bench/下行命令台架测试_V0.1.md`第11行；该文件的2026-09-02实测段记载更换为H/L可选触发继电器及继电器/12V风机运行约10秒后停止。
本表按用户沿用原5V继电器模块编写，当前未重新量测供电。继电器模块DC+使用5V，COM触点使用风机12V正极，两条正电源线分开。
触点上的10A、250VAC或30VDC等字样是触点负载额定值，不是DC+供电值。若换成其他额定电压的模块，须另核对，不能沿用本表的5V。
全部断电接线，接好并检查后再逐台通电；两块INA逻辑VCC仍是3.3V。

### PWM三极管E/B/C及原基极电阻

已读取原“开展台架测试并接入传感器”对话（thread `01a0cdd0-d80b-79c1-afb0-4d604983c2f2`）。
turn `01a0d134-39cf-7b43-8885-5cd8b210ea08`给出E接地、C接PWM；其后turn `01a0d136-bbc5-7922-b0f0-d5c49d2ce8e5`明确更正：保留原GPIO到B之间的10kΩ串联电阻，不必改为前一条建议的1kΩ。
这里是历史对话接法的恢复，不是本次对电阻值或三极管管脚的实物量测。

```text
风机1：4号板PB8 ── 原10kΩ ── B
                             E ── 公共GND
                             C ── 风机1 PWM信号线

风机2：2号板PB1 ── 原10kΩ ── B
                             E ── 公共GND
                             C ── 风机2 PWM信号线
```

公共GND包括对应主控GND、风机负极及12V电源负极。TACH不经过这只三极管，仍分别回各板PA7。
10kΩ串联电阻与B-E之间可能另有的下拉电阻是不同支路；原串联电阻不能改接成下拉。
本次未找到足够的型号/封装证据确定“平面朝向、从左到右”的物理脚序，按实际E/B/C标识或对应型号资料辨认，不能仅凭外形排列猜。

## 1. 接线前状态

- 先断开12V风机电源再移线；低压主控也断电后接插件。旧风机线束保留标签，旧输出不与新板并接。
- 先完成风机1（4号板），验证后再做风机2（2号板）。
- 本地固件在2/4号烟雾或火焰输入触发时，会强制继电器接通、风机100%；网页禁用控制不能禁止这条本地行为。因此接线时保持12V断开。
- 只有两个风机支路，没有水泵。两个主控的同名针脚是各自独立信号，不互相短接。

## 2. 主控端接线

| 接线功能 | 风机1／FAN-01 | 风机2／FAN-02 |
|---|---|---|
| 所属主控 | 4号CTRL-04 | 2号CTRL-02 |
| 对应继电器IN／高有效 | 本板PA1→继电器第1路IN | 本板PA1→继电器第2路IN |
| PWM驱动输入 | 本板PB8→原三极管基极限流电阻的输入端 | 本板PB1→原三极管基极限流电阻的输入端 |
| 原三极管输出 | 原集电极→风机1的PWM线 | 原集电极→风机2的PWM线 |
| 原三极管地 | 发射极沿用原GND | 发射极沿用原GND |
| 转速反馈 | 风机1 TACH→本板PA7 | 风机2 TACH→本板PA7 |
| TACH上拉 | 保留原上拉至3.3V的接法 | 保留原上拉至3.3V的接法 |
| INA226 SCL | 本板PB6 | 本板PB10 |
| INA226 SDA | 本板PB7 | 本板PB11 |
| INA226逻辑VCC | 本板3.3V | 本板3.3V |
| INA226 GND | 本板GND | 本板GND |

原基极限流、偏置和驱动结构整体保留，不按三极管外形猜B/C/E脚序。
2号PB8已用于屏幕CS，风机2必须接PB1。4号PC10原基极线不保留到新输出，不把旧PB9、PA15等输出与新控制脚并联。
若继电器是两个单路模块，两块都可能只标IN；若是一块双路PCB，分别使用IN1/IN2。
原H/L可选触发模块DC+沿用5V、DC−接GND，跳帽H；不能把继电器线圈供电接PA1。保留原IN到GND约10kΩ下拉，复位时不应误吸合。

## 3. 每台风机的12V功率回路

以下为功能端子，不是插头从左到右的针序：

```text
12V电源正极 → 支路保险/限流 → 对应继电器COM
对应继电器NO → 对应INA226的IN+
INA226板载R010分流通路 → IN− → 对应风机+12V
风机GND → 12V电源负极

12V电源负极、本板GND、INA226 GND和原三极管GND共参考
```

- 使用COM和NO；NC不接。两个继电器触点分别串入两个支路。
- 风机电流必须流过INA的分流电阻，不能另接一条12V旁路线直接到风机正极，否则电流测不到。
- IN−是正电源经分流之后的负载侧，不是电源负极。
- 若模块另引出VBUS且没有内部连接，接负载正极（IN−侧），用于测风机端电压。若模块已内部连接则沿用，不凭端子外形重复改线。
- INA逻辑VCC是3.3V；12V仅进入测量/负载回路。TI区分VS逻辑供电与VBUS测量输入，见下方数据手册。
- 大电流回路用原适当接线端子及电源线，不经过面包板细信号跳线、STM32 3.3V或USB供电针。
- 若RGB本来随风机电源亮灭，维持原供电方式，不新增ARGB控制线。颜色不能用来猜PWM/TACH或电源针序。

## 4. INA与温湿度共用I²C

两块INA分别并入其所属板的现有I²C：SCL并SCL、SDA并SDA，温湿度模块仍保留。
INA地址0x40与温湿度0x44/0x45不同；两板总线不能互接。I²C上拉仍到3.3V，不把两块主控的3.3V稳压输出并联。
接入INA后先确认原温湿度仍持续更新，避免总线被拉低或引入5V上拉。

## 6. 通电与验收顺序

1. 12V仍断开，先完成INA逻辑接线；读到INA且原温湿度未受影响。
2. 检查继电器复位时不吸合、原下拉存在，PWM经过三极管且TACH上拉为3.3V；当前烟雾/火焰未触发。
3. 完成2/4号R010参数更新后，逐个开启对应12V支路，核对对应继电器及风机，另一台不误动作。
4. 接通继电器、先以100%可靠启动，再验证75%、50%等PWM值，记录TACH与电流变化；不能用继电器触点做25kHz调速，0%PWM也不能代替断电停机。
5. 对照实际测速及参考电流核验PPR、方向和比例；核验后再带实测记录启用反馈已验证标记。
6. 最后验证风机供电与RGB、实际RPM与模型叶片各自对应。断电后允许惯性滑行，不要求RPM瞬间归零。

当前网页实物配置仍为只接收数据；接线核验后再安排受控调速测试，未自动解除该限制。本文件不表示已经带电验收。
