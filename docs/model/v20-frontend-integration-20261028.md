## 复现

在已经初始化的独立实物联调环境中：

```powershell
$env:DJANGO_SETTINGS_MODULE='config.hardware_live_settings'
python backend/manage.py install_twin_v20
python deploy/hardware-live/verify_ingestion.py --seconds 6 --expect-presentation v20-presentation-20261028.1
node tools/verify-model-v20.mjs
```

Python需使用已安装项目锁定依赖的环境。源模型由Git LFS管理，首次克隆需取得实际GLB，SHA不符时安装命令拒绝启用。
当前联调环境已完成切换，无需再次执行安装命令；网页刷新并点击“总览”即可查看完整布局。
