## MVP接线边界

```text
STM32F103RCT6
├─ GPIO输入：震动、DHT11数据、水浸阈值（或ADC）
├─ GPIO输出：蜂鸣器、继电器、风机IN-A/IN-B、WS2812B数据
├─ SPI：1.44英寸TFT
├─ USART2：ESP8266（待采购，核心MQTT链路）
└─ USART1：调试串口；蓝牙仅作为可选近端调试
```

## 必须补齐的关键硬件

当前库存可以迅速搭建本地采集、声光提示、风机联动和水浸演示，但不能替代项目的关键测点。MVP前仍应优先采购：

1. SCD40 CO₂传感器和合规低浓度CO₂标气/限流组件；
2. SHT30/SHT3x作为核心温湿度传感器；
3. ESP8266通信模块；
4. 浮球高水位、进/出水流量传感器、低压泵、受控阀和接水盘；
5. 烟感模块，以及风机转速或电流反馈模块；
6. 适配电源、保险、端子、MOSFET/驱动保护、电平转换和线缆标识。

## 安全与验证要求

- 所有模块第一次接线前，先核验VCC、电平、功耗和接口类型；STM32 GPIO默认按3.3V处理。
- 继电器、风机、泵和灯带与MCU分供电；水路附近仅布置低压部件，控制PCB和插座高于最高可能水位。
- 水浸与土壤湿度裸电极不能长期持续供电；演示结束后擦干并断电。
- 蓝牙仅用于近端调试，不能替代MQTT、权限、日志和工单闭环。
