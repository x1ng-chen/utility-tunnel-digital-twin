## MVP接线边界

```text
STM32F103RCT6
├─ Node A PA1：继电器输入（高电平吸合）
├─ Node A PC0：FS-IR02 DO（5V信号经10k/10k分压，低有效）
├─ Node A PB6/PB7：SHT30 I²C
├─ Node A PB12：烟雾模块DO（低有效）
├─ Node B PB4—PB9：ST7735S TFT软件SPI
├─ PB0：MH-FMG有源蜂鸣器（高电平响；Node A专用，启动默认低电平）
├─ PB15 / SPI2_MOSI：WS2812B灯带DIN（经74AHCT/74HCT单向3.3V→5V电平转换；Node A专用）
├─ PA2/PA3 USART2：ESP8266-01S（Node A与Node B均为9600 bit/s）
└─ USART1：下载/调试串口
```

## 必须补齐的关键硬件

当前库存可以迅速搭建本地采集、声光提示、风机联动和水位演示，但不能替代项目的关键测点。MVP前仍应优先采购：

1. 甲烷（%LEL）、一氧化碳（ppm）和氧气（%VOL）专用传感器；优先选UART/RS485输出模块，并确认数据手册、预热时间、量程和交叉敏感说明；
2. SHT30/SHT3x作为核心温湿度传感器；
3. ESP8266-01S已到手并完成STM32→ESP8266→IoTDA真实数据上行；需补齐日志/截图归档、断网重连和连续运行验收；
4. 浮球高水位、高边接水盘、隐藏滴水器和吸水材料；
5. 烟感模块、隔离式多路传感器信号模拟盒，以及风机转速或电流反馈模块；
6. 适配电源、保险、端子、MOSFET/驱动保护、电平转换和线缆标识。

## 安全与验证要求

- 所有模块第一次接线前，先核验VCC、电平、功耗和接口类型；STM32 GPIO默认按3.3V处理。
- 继电器、风机和灯带与MCU分供电；滴水演示点附近仅布置低压部件，控制PCB和插座高于最高可能水位。
- 水位与土壤传感器的裸电极不能长期持续供电；演示结束后擦干并断电。
- HC-05/JDY-31类蓝牙串口模块已停用，不再接入、维护或纳入验收。
- ESP8266-01S不得接5V；首次上电前核验3.3V供电峰值能力、EN/GPIO0/GPIO2启动电平和UART交叉接线。
- 甲烷、CO、氧气模块必须真实接入用于环境基线采集；教室内禁止以打火机放气/点火、释放CO或置换氧气的方式测试。异常演示只使用隔离信号模拟盒；烟雾仅使用合规测试气雾和小型测试罩。
- 实物到位后，王为和闵昊完成逐项“电压—接口—驱动—联动”核验；胡雨皓记录测试证据。

## V18 加工与安全评审细化（2026-08-31）

- FS-IR02 的5个模型支架均改为**无孔径假设的分体夹具**：仅保留板卡约38.6×22.1mm和可调外形，不把既有模型中的探头外形当作钻孔依据。每套必须实测探头螺纹外径、螺母对边和线缆长度后，才可冻结孔径、夹具内衬和走线余量。
- 两台风机仅确认120×120mm外框；模型中不再表达可用于加工的四孔孔距。孔距、孔径、厚度、额定/启动电流、PWM输入与TACH输出定义均须由实物标签或数据手册复核。
- 新增IF-01“5V传感器域—3.3V控制器域”评审位：5V保险规格、DO有效电平/限流或隔离方式、AO分压/缓冲/保护与ADC满量程均为待评审项，禁止直接将5V DO/AO接入STM32 GPIO/ADC。
- P-01在模型中以进、出水干帽及24V服务断开状态表示，V-01以锁闭表示；软管内径/外径、泵口外径、启动电流、保险、继电器触点能力和漏水/绝缘测试均未冻结。未经项目负责人批准，不得去除干帽、带电或通水。
