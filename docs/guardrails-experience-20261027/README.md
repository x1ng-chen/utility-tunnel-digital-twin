# 护栏、联合评测与受控复核经验

本轮实现确定性护栏、联合评测以及管理员审核的项目内共享提醒。网页验收记为**用户确认通过**；新增页面交互另外用浏览器响应桩回归。没有运行付费模型，没有真机控制，也没有新增预测、MCP或自动结单。

入口：[规则与矩阵](rules-and-matrix.md)、[审核与复现操作](operations.md)、[离线结果](offline-summary.json)、[完整离线记录](offline-records.zip)。旧的12个复合场景、30题以及[历史回复与人工评分材料](../agent-evidence-quality-20261027/README.md)继续保留，不能把本轮桩测试并入真实模型成绩。

## 已实现

- 三Agent和单Agent使用同一确定性校验。保留120秒、12次模型调用、12次工具调用总上限。缺项时可以继续只读取证；错误结构化断言会保留原始证据并阻断本次结果，不能生成可确认动作。
- 规则结果独立放在`guardrails`，带规则编号、版本、设备、来源、快照散列、E证据和缺项。E表示原始工具记录，G表示规则推导，K表示知识片段；G不能充当原始数值事实。模型解释单独展示。旧任务不倒填。
- 同风机有效RPM才能支持本来源下的转动判断；电流与零转速组合只提示继续核查，不推断唯一机械根因。原始气体量不宣称可信浓度或梯度。恢复需工单之后的新观测、适用阈值、有效质量及活动告警核查，不自动结单。
- 只有“要求修改→诊断实际修改→再次复核通过”的新任务才生成候选。候选采用固定白名单模板，不复制提示词、完整模型回复、凭据或私有轨迹。模型通过不等于知识正确。
- 管理员批准后才能检索；原始任务仍只对所有者开放。按工位、设备/指标、布局、知识、规则和数据来源匹配，每次最多3条，每条最多300字。经验仅为低信任提醒；不作为E事实，不批准动作，不扩权。
- 批准内容不可覆盖；修订生成新候选，批准新版本时退役旧版本。过时分支、重复审批、内容散列不一致和旧版本来源不能获批。任务冻结实际加载的条目、内容和散列。

## 验证口径

| 层次 | 本轮结果及限制 |
|---|---|
| 软件测试 | 后端完整回归、前端单测/构建及GitHub CI；具体结果见PR检查，不能替代现场验收 |
| 联合矩阵 | 24例加1例能力边界，单/三Agent×经验关/开，共100次明确标记的桩执行 |
| 确定性拦截 | 每臂12例违规均正确拦截，12例合法对照均未误拦；这是契约测试，**不是模型拦截率** |
| 经验相关 | M01～M08覆盖生成、审批、隐私、匹配、并发版本、退役、恶意内容和留出上下文 |
| 历史重放 | 本轮未重新评分历史回复；保留原始记录与现有人工评分入口 |
| 真实模型 | 暂缓；真实用量、费用、任务效果、经验收益和单/三Agent优势均待显式复测 |
| 人工审核 | 发布夹具仅做程序模拟审批，标记`SIMULATED_ADMINISTRATOR_NOT_HUMAN`，不计真人审核 |

四臂共享每个案例的`observationHash`；同一经验条件下，单/三Agent共享完整`snapshotHash`。训练例独立记录为`TRAINING_FAN_MISSING_ONLY_NOT_J01_J25`，不从留出案例答案生成提醒。原始ZIP包含每次任务、失败/阻断、工具轨迹、冻结数据、版本与耗时；`offline-summary.json`保留未知的实模成绩和费用。

现有12/30题本轮只校验目录并保留原有回归；没有将其全部重新调用真实模型。三Agent增加了协作过程，**是否提高效果仍需真实模型配对与人工评分**。

## 能力边界

合法格式的伪造RPM，在没有独立对照时可能通过；J25单列，不计入应拦截分母。有效RPM字段是一种证据契约，不能保证传感器和上游系统没有伪造。护栏验证结构化事实/断言及动作条件，不能自动验证全部自然语言。

数值原始事实继续遵守`facts`绑定：设备、指标、数值、单位必须存在于所引E记录。A/mA的规则换算放在`derivedCurrentAmps`，不改写原始测量。当前恢复只表示**对应来源及已配置上限规则**的新观测支持，不能据此给出人员安全进入或可信氧浓度结论。

经验的词法过滤不是完整脱敏证明；管理员仍需逐项核查隐私、相关性和不当指令。出现问题可立即退役并关闭服务端检索开关。真人复核、模型重测及实物验收继续分别记录。
