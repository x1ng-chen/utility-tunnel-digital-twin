# 项目当前状态与版本索引

## 当前重组基线（2026-10-24）

[总体方案V1.1](four-controller-overall-plan-2026-10-23.md)以用户提供的实体外形700×700×300 mm为准，四块STM32按左上01、右上02、左下03、右下04分布。五检测站按四角加中央布置，P1/P2/P3/P4分别在四区、P5中央；CTRL-03负责P3/P5，CTRL-04负责P4，31路归属仍为7/6/11/7。设备标签与三维绑定及验收要求见[五站布局与报警定位](five-station-layout-700-square.md)。

业务管线按用户草图设置两个进口、两个出口；两台风机排舱内空气，不能接在管道出口上。两块ESP32-S3分别承担RS-485/MQTT网关与小智语音终端；带SW1的JSM485模块选型保持，采购到货与五节点稳定性尚未验收。

用户已授权模型专用对话继续制作，并于2026-10-24授权同步最新尺寸和布局。模型任务按[协作清单](four-controller-collaboration.md)进行独立修订；旧1000×400×450 mm的V15仅为历史概念，不能作为当前模型已完成证明。新模型必须逐站验证告警到具体传感器的三维定位。引脚、供电、Modbus寄存器、保护状态表与整机联调仍待完成。

本次更新方案与协作入口，不修改固件、运行GLB或平台服务。Agent进阶实现参考[2026-10-14快照](https://github.com/x1ng-chen/utility-tunnel-digital-twin/tree/a783b318d748b970eb0a8f6bc03aac58037e434e)，不推定已合并或部署。
