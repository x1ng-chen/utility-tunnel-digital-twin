## 功能与交付边界

- 软件：Vue/Django 已实现资产、权限、遥测、告警、工单、审计、数据洞察、GIS 与三维。AI 助手位于登录页之后的右下角，解释页面及一般流程；不读取实时数据库或控制设备，详见 [AI 接入](AI助手接入.md)。AI 需要外网和后端密钥，核心本地运维链路不依赖 AI。
- 模型：当前台架网页使用用户指定 V13 的导出 GLB；V07 为旧运行基线/回退参考。SHT 模型位 03 留空，氧气使用 01/03/05；部分资产模型节点元数据仍待补齐。
- 固件：FLAME-01 短触发上报与蜂鸣器清警后释放引脚修复已提交功能分支；构建、烧录、台架复测和长期可靠性应分别记录。
- Carrier32：仅为设计与展示草稿，布线、电气/机械复核和制造发布门禁未通过；本次项目方验收不等于制板放行。
- 工程：模拟量标定、INA226 精度、逐路故障/断线、长稳和恢复、生产部署与备份恢复演练仍须独立验收。
