## 2026-09-10 实时流与三维趋势增量（仍待完整验收）

- 新增 `/ws/events/` 的 Django Channels ASGI 下行事件流：首帧 Bearer 认证、Origin 白名单、认证超时/撤销/禁用检查、epoch+seq、有限重放、游标失效时明确 `reset` 并由前端 REST 补读；浏览器 token 不写入 URL。遥测、告警、资产和工单在事务提交后才广播，前端以增量 upsert 合并并在 REST 快照竞态后重放新事件。
- 容器 API 改用单 Daphne ASGI，Nginx 转发 `/ws/` Upgrade，部署检查与专属后端/前端测试通过。该实现只覆盖同一 API 进程；独立 monitor、多副本、持久跨进程游标尚未实现，不能把本项记为第 1096 段完整生产验收。
- 三维设备详情趋势复用时间轴图表并保留缺失值断点，避免以前按类别等距平滑连线；只说明当前已加载样本，未推断隐式缺失或完整历史。

1. 完成启动与连接可靠性，避免演示入口失败；保留当前框架与原有数据库。
2. 明确历史分析/导出数据口径并补齐软件功能；核对自动定位和告警时延。

5. 冻结后完整测试、逐文件审查、长时稳定性、合并队友提交、推送并核验CI。
