# 四路液位台架接入记录（2026-09-26）

本记录基于用户现场操作回复、STM32 BootLoader UID/回读校验，以及电脑在本地 MQTT `1884` 端口收到的实时遥测。`good` 表示固件已采样并发布该数字输入，不等于完成了电压、断线或长期稳定性验收。

## 接入范围

| 测点 | 节点及引脚 | 本轮固件状态 | MQTT 实测 |
| --- | --- | --- | --- |
| L01 / `LEVEL-01` | Node A PC0 | 已启用 | 湿 `1/good`，擦干后 `0/good` |
| L02 / `LEVEL-02` | Node A PC12 | 本轮启用 | 湿 `1/good`，擦干后 `0/good` |
| L03 / `LEVEL-03` | Node A PC13 | 本轮启用 | 湿 `1/good`，擦干后 `0/good` |
| L04 / `LEVEL-04` | Node B PC10 | 本轮启用 | 湿态固定后 55 秒内连续 11 次 `1/good`，擦干后连续 `0/good` |
| L05 / `LEVEL-05` | Node B PC11 | 保持禁用；用户已拆除实物 | `0/missing` |

用户逐次操作探头并回复完成。初次切换窗口内 L03/L04 的读数有未稳定状态；在用户确认固定状态后重新监听，L03 干态为 `0/good`，L04 湿态连续保持 `1/good`。L01 擦干后第一轮仍为 `1/good`，再等一轮回到 `0/good`。这说明不能把某一帧的旧值当作当前触发结果。

Node A 固件设定每 2 秒轮换发送六类遥测帧；本轮 MQTT 实际观察到相邻 Node A 帧约隔 6–8 秒，一次完整轮换可能约 40 秒。L02 位于第 4 帧，L03 位于第 6 帧；因此实机判断按连续轮换观察，不以 20 秒无变化判失败。

## 待补证据

- L01–L04 的传感器 VCC、模块 DO 干/湿电压、分压后的 MCU 引脚干/湿电压尚未收到具体仪表数值；不能据此宣称电气保护验收完成。
- 四路断线状态和长时间稳定性未测。数字输入的 `good` 目前只表示采样有效，不能自动诊断断线。
- 本轮未核对 Django 资产入库和页面联动；IoTDA 网关运行进程尚未因代码变更重启。
