# 四主控重组与语音Agent协作任务

更新日期：2026-10-23。共同设计基线：[四主控总体方案](four-controller-overall-plan-2026-10-23.md)。

## 如何参与

1. 阅读总体方案，核对“已确认”和“待冻结”；下表负责人默认“待认领”，不自动指派人员或推定贡献。
2. 用一个PR认领一个任务或明确的小范围，在本表填负责人、工作分支、实际基线提交和PR链接。表中建议分支名尚未创建，不能据此直接切换不存在的分支。
3. 开始代码工作前核对main、旧台架和Agent分支差异，选择并记录实际集成基线。main上的新方案文档不代表功能分支已合并。
4. 跨模块字段或行为变更先更新接口文档，由生产方与消费方核对；不要各自解释字段。
5. 完成后补交付物、自测与联调证据，由非作者复核后标“完成”。只有代码、尚未实物联调时标“实现待验收”。
6. 建模任务当前“暂停”；完成前置空间评审并获负责人明确恢复指令后才开始，不直接发布新GLB替换旧运行模型。

## 提交与复核约定

- 功能以PR集成，跨模块变更由接口另一方核对；沿用仓库既有协作约定。
- 只提交任务必要文件；本地密钥、设备凭据、运行日志中的敏感内容先脱敏。
- 不把本轮讨论截图中的促销价、最大距离、零丢包宣传写成验收结果。
- 不改变设备控制权限、本地保护或建模暂停状态来绕过依赖。
- 发现归属、接口或供电前提不成立时，记录证据并修订总体方案，保留变更记录。
- 本表是可共同编辑的任务入口；本次发布不自动分配成员、不通知或邀请新的协作者。
