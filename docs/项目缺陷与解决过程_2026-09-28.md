## 处理方法的共性

1. **先分层定位**：供电/引脚与启动 → 串口帧 → Wi-Fi → MQTT → 网关 → Django → 页面。保留时间戳和设备 UID/MAC，不能只根据 COM 号或指示灯判断。
2. **区分修复级别**：源码构建、写后回读、短时实机、断网恢复与长稳分别记录；测试通过不自动提高其他级别的状态。
3. **以可信数据驱动告警**：原始读数保留质量标记；仅 `good` 数据参与统计与阈值；命令要有设备执行回执，不把 MQTT `published` 当作执行成功。
4. **保留 Demo 边界**：2026-09-27 负责人确认的是课堂展示范围。未标定的气体数值、未布线 PCB、未合并 PR 与未运行远端 CI 均不得写成工程验收完成。
