# 软件测试报告

> 基线：P0–P3 软件交付 · 更新：2026-08-26

| 层级 | 命令/方法 | 验证目标 |
| --- | --- | --- |
| Web 静态与构建 | `cd apps/web && npm run check` | ESLint、TypeScript、11 个单元测试和生产构建 |
| Web 覆盖率 | `cd apps/web && npm run test:coverage` | 操作状态机、API 映射、坐标配置的覆盖率报告 |
| API 静态与单元 | `cd services/api && npm run build && npm test` | 生命周期、权限拒绝与速率限制 |
| API 覆盖率 | `cd services/api && npm run test:coverage` | API 纯业务模块的覆盖率报告 |
| 迁移安全 | `cd services/api && npm run migration:check` | 有序命名且不包含破坏性 DDL/DML |
| PostgreSQL 集成 | GitHub Actions API job | PostgreSQL 18、迁移、种子、登录、筛选、阈值、导出、手工工单、告警-工单闭环与审计冒烟 |
| 浏览器 E2E | Playwright 本地实际浏览器 | 本地演示模块导航、筛选、业务操作与 API 登录失败提示 |

## 通过标准

所有 P0/P1 阻断问题为零；构建、迁移检查、单元测试和数据库冒烟测试必须通过。真实托管数据库在部署阶段另按部署手册完成备份恢复演练。
