# 软件测试报告

> 基线：P0–P3 软件交付 · 更新：2026-08-28

| 层级 | 命令/方法 | 验证目标 |
| --- | --- | --- |
| Vue 3 静态与构建 | `cd frontend && npm test && npm run build` | 29 个单元测试、TypeScript 类型检查和生产构建；含 GIS 坐标、GeoJSON 导入/发布映射、资产写入权限、遥测筛选/汇总、混合量纲保护、空结果和时间边界校验 |
| Vue 3 依赖审计 | `cd frontend && npm audit --registry=https://registry.npmjs.org --omit=dev --audit-level=high` | 生产依赖高危漏洞为零 |
| Django 静态与单元 | `cd backend && python manage.py check && python manage.py test` | 58 个接口、生命周期、权限、分页、审计、事务、配置、幂等、单管理员审批注册、弱口令拦截、用户管理、资产主数据、GIS GeoJSON 审核发布、空间窗口筛选、硬件接口预留、可信遥测、遥测历史统计、自动阈值告警、数据治理和安全测试 |
| Django 生产预检 | `cd backend && python manage.py production_preflight` | 生产安全配置、TLS 反向代理信任、PostgreSQL/TLS、共享缓存、数据库连通性和迁移状态 |
| 数据治理报告 | `cd backend && python manage.py data_governance_report --format=json` | 只读统计遥测、审计和导出记录的保留期候选，不执行删除 |
| Django 迁移安全 | `cd backend && python manage.py makemigrations --check --dry-run` | 模型与迁移一致，不遗漏数据库变更 |
| 字节码检查 | `cd backend && python -m compileall -q config operations` | Python 模块可编译、无语法错误 |
| 仓库安全扫描 | `node tools/quality-scan.mjs` | 工作区跟踪及未忽略文件中的真实环境文件、私钥和常见云平台令牌检查 |
| PostgreSQL 部署 | `deploy/postgres/*.ps1` | TLS、最小权限、备份校验、隔离恢复和恢复后数据探针（需部署环境执行） |
| 浏览器 E2E | `.github/workflows/browser-e2e.yml` | 9 个隔离浏览器流程：验证账号登录、三维设备定位与全屏设备栏拖动指针、GIS 实物模块、遥测质量筛选与 API 历史源、告警确认、审计读取，以及管理员导入、审核发布 GeoJSON 并回读运维地图；同时检查控制台错误。CI 仅对隔离测试进程放宽登录节流，正式环境默认仍为 10 次/分钟。 |
| 容器制品检查 | `node tools/check-deployment-artifacts.mjs` | Docker API/Web 制品、Nginx 路由与 CSP、非 root、只读文件系统、回环端口与密钥占位符检查 |

## 通过标准

所有 P0/P1 阻断问题为零；构建、迁移检查、单元测试和数据库冒烟测试必须通过。生产配置缺少安全 Origin、主机、数据库 TLS 或共享缓存时必须启动失败。真实托管数据库在部署阶段另按部署手册完成备份恢复演练。
