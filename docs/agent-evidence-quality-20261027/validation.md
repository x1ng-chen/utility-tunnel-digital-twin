## 明确保留的待验事项

- 余额补足并获明确启动后，以冻结的新版本重跑真实模型；目前没有新增付费请求。
- 人工组实际完成任务；其他评分员独立核对回答、引用适用性、推断和完成情况。
- 同模型、同事实与知识、同预算的单/三Agent新配对；旧日志没有预算元数据，不倒填为已验证。
- 标准全文覆盖与后续变更复核；选定摘要不是工程合规结论。
- 工单超过80条时保守拒绝草案；按设备分页需要另行增加。
- 当前本地运行的服务需重启后加载后端代码；本轮没有通过网页启动真实模型任务。
- 实物、语音、公网部署和长期现场运行继续暂缓；模拟结果不能替代这些验收。
