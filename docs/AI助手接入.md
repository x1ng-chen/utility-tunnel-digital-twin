# 管廊运维 AI Agent 接入

平台登录后的页面右下角提供 DeepSeek 运维 Agent。它通过后端白名单工具查询资产、活动告警、最新遥测、近时指标统计、未完成工单和项目内部排查手册，返回工具轨迹及带查询时间的证据。支持生成工单草案，有权限的人员审阅并二次确认后，前端调用既有工单接口创建；Agent 本身不会修改数据库业务记录或执行硬件控制。

页面只提交最近五轮对话和当前页面名称，不会回传客户端的工具证据；后端每次重新读取数据库。对话和原始证据仅在浏览器内存保留，退出登录时清除。服务端审计保存工具名称、状态、耗时、草案数量和请求编号，不保存完整聊天或原始遥测。必要的工具结果会发给 DeepSeek，接入真实场地前应获得数据出境/外部服务使用授权并评估脱敏。

## 后端配置

在后端的未跟踪 `backend/.env` 中配置：

```dotenv
DEEPSEEK_API_KEY=在本地填入你的密钥
DEEPSEEK_MODEL=deepseek-flash
AI_ASSISTANT_RATE_LIMIT=20/hour
```

配置后重启 Django 服务。密钥只在后端使用；不要放进 `frontend/.env`、任何 `VITE_` 变量或浏览器代码。页面需要登录正式数据服务，演示登录模式不会调用付费接口。

容器部署时，在服务端环境提供同名变量；生产 Compose 仅向 `api` 容器传递密钥，网页构建和浏览器都不会接收它。

后端的 `POST /api/assistant/chat/` 要求可读取运维页面的 Bearer 登录凭据，采集服务账号不可调用。每次最多接收 12 条消息、每条最多 2000 字、总计最多 8000 字；只接受 `user` 和 `assistant` 角色，最后一条必须由用户发送。默认每名用户每小时最多请求 20 次。

请求处理最多 4 次模型调用、6 次工具调用；模型请求总时间预算 55 秒（单次网络超时至多 18 秒），前端超时 65 秒。仓库生产容器的 Gunicorn 默认超时与 Nginx 上游读取超时均已改为 75 秒；Gunicorn 可用 `GUNICORN_TIMEOUT` 覆盖。另有云端负载均衡/代理时应核对其超时，避免中断工具循环。数据库查询耗时不具有硬实时保证。模型调用不自动重试，以免放大费用和重复业务意图。

工具参数在后端校验：只允许指定工具及字段，资产必须真实且启用，趋势窗口为 1–60 分钟。资产列表上限 80，告警/工单上限 15，快照每资产上限 20 项指标，趋势只统计最新 500 个样本、最多 30 个单位/质量分组，并明确截断范围。不允许任意 SQL、shell、文件、URL 和 MQTT 指令。

生成草案需要运维员/管理员权限，且同次请求已查询该资产快照与未完成工单。草案不创建记录；用户确认后使用现有工单权限和幂等键，失败重试复用同一键。跨对话新草案并不具有语义去重保证，用户仍应核查已有工单。写入保留既有工单审计。

返回字段：`reply`、`queriedAt`、`mode`、`traces`、`evidence`、`proposals`。`tool_verified` 只代表调用了工具，不代表大模型全部表述已被自动事实校验；每项证据应逐项核对。`explanation_only` 表示未成功调用任何工具，不可视作已查询现场。

数据新鲜度沿用平台心跳宽限设置（间隔乘系数与最小宽限取较大值）；无绑定/无心跳为未知，不擅自假设在线。返回采样/接入时间、质量、新鲜度和未来时间戳警示。不同单位与质量不混合统计，坏质量只计数，不计算平均值。数据库快照不是持续实时流，原始气体 ADC/电压不是标定浓度，项目内部手册不是现场批准的安全规程。

DeepSeek 接口地址固定为 `https://api.deepseek.com/chat/completions`，默认使用 `deepseek-flash` 非思考模式；如需更强的模型，可将 `DEEPSEEK_MODEL` 设为 `deepseek-v4-pro`。助手回复仅供参考，现场状态以设备、告警和工单页面的实际记录及人工核查为准。

## 验证与使用

后端回归：`python manage.py test operations.test_ai_assistant operations.test_ai_agent --noinput`。

前端：在 `frontend` 执行 `npm test`、`npm run build`。组件测试覆盖二次确认、只读角色、失败重试幂等；Store 测试覆盖证据不回放及退出后迟到响应丢弃。

建议先问“查询 CTRL-01 的最新采样和数据新鲜度”，打开“核查过程与证据”查看实际时间和值；再问“检查活动告警，检索排查手册，给相关资产生成处置工单草案，先核对已有工单”。如果工具预算不足，请缩小到单个资产分步提问。重启后端/重新构建运行前端后生效，不需要修改 STM32 固件。

本地模拟上游测试不等于真实 DeepSeek 模型效果验收，真实数据联调、外部访问、时延/费用、提示注入红队及现场安全审批仍需完成。
