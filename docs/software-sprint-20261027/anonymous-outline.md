# 匿名参赛材料提纲

1. 城市管廊运维问题：多设备、跨位置证据分散、误把控制意图当执行、处置过程难追溯。
2. 系统：五站31传感器、四节点与双排风机的软件映射；当前演示来源为仿真。
3. 创新：独立取证/诊断/复核与受控执行、固定证据快照、三维绑定、版本化知识片段。
4. 演示：异常→排障→复核→人工确认→模拟回执→新测量复核→工单报告。展示至少一个失败或证据不足案例。
5. 实验：同源数据包、同模型与总预算；单/三Agent及普通问答结果；人工评分另列；使用实际耗时及正确数，报告全部失败。
6. 价值：双风机与工时当量的可配置测算，展示未知区间与假设，不能把估算写成实际节能或避免事故。
7. 限制与后续：修订标准全文待补、AO-02及气体标定待实测、真实MQTT/RS-485、小智与公网待验收。
