# 软件使用手册

## 登录与账号申请

1. 前端默认使用部署时的 `VITE_API_BASE_URL`，登录页不提供地址输入。开发与自动化测试可使用浏览器本地 `vue-api-url` 覆盖；正式演示前应清理测试覆盖值，避免连接错误的数据服务。
2. 使用管理员分配的账号和密码登录。Bearer Token 仅保存在当前标签页的 `sessionStorage`，关闭标签页后清除；仍应把前端部署在 HTTPS 下并防止 XSS。
3. 新用户只提交账号、姓名和角色，不提交密码。管理员批准后会生成一条 24 小时有效、仅显示一次的密码设置链接；设置成功后账号启用，链接立即失效。
4. 连接失败时检查 API 地址、`CORS_ALLOWED_ORIGINS`、账号状态以及 `/api/ready/`。

## 日常操作

1. 在告警中心确认事件并按需创建关联工单。
2. 在工单中心依次完成派发、处置、复核和关闭，禁止跳过受控状态。
3. 在资产台账按名称、区域和状态筛选；在数字孪生或 GIS 中定位资产。
4. 报表由服务端对完整数据库查询生成 CSV，不受前端当前分页限制；下载行为写入审计日志。
5. 管理员可在系统配置中维护阈值、账号审批和用户状态。

## 导航与反馈

- 桌面左侧导航按运行工作台、平台治理分组；收起后通过图标进入页面，展开按钮仍在顶部。窗口较矮时可滚动导航，不必缩放整个浏览器。
- 窄屏采用底部导航，左右滑动可访问其他入口。页面滚轮只滚动当前内容，不会切换业务页面。
- 顶部搜索可查找设备、告警、工单或页面；不要把页面搜索结果误认为全库统计。
- 操作提示在页面上方显示约 3 秒后自动消失。若表单仍显示校验错误，应先修正输入；不要仅凭提示消失判断操作成功。
- 离线状态下数据仅供查看。待数据服务恢复后再执行修改，设备离线与数据服务离线是不同概念。

## 三维孪生查看

1. 选择“总览”或设备，可快速定位查看对象；模型状态和设备状态应分别查看，模型成功加载不代表设备在线。
2. 工具栏可切换平移与旋转：平移模式为左键平移、右键旋转；旋转模式为左键旋转、右键平移。
3. 滚轮指向缩放，方向键可平移；迷失视角时使用重置视角恢复总览，不必刷新网页。
4. 底部设备快速切换支持筛选、横向滚动和选择设备；异常巡检按钮依次定位异常设备，不会自动处理或关闭告警。
5. 全屏查看保留工具栏和设备选择；退出全屏后可继续在右侧查看相关信息。

## 工单为什么需要推进阶段

工单是处置记录，不是自动维修指令。按顺序执行“待分派 → 已分派 → 处理中 → 待复核 → 已完成”，表示任务责任和验收状态发生变化。只有实际完成当前阶段的工作后才点击推进；提交复核需记录处理结果，管理员完成复核需填写结论。点击后卡片进入相应列，不代表设备故障已经自动消除。

## 修改阈值与处理冲突

- 在系统配置输入预警值和报警值，报警值必须高于预警值。保存期间等待结果，不重复点击。
- 如果其他会话已修改同一配置，页面保留你的草稿并阻止覆盖。先记录需要保留的输入，再点击“放弃草稿，载入最新值”，核对后重新填写并保存。
- 载入最新值会明确丢弃当前未保存草稿。若网络不可用，应先恢复连接，不能用旧快照强行覆盖。

## 空间点位登记

管理员在空间配置填写对象编码、名称、真实经纬度及来源依据；没有精度资料时留空，不填写猜测值。登记后的对象仍需审核发布，只有已发布对象才进入运维地图。示意锚点、真实坐标和硬件连接状态不可互相替代。

## 遥测接入

IoTDA 网关使用 `X-Ingest-Key` 机器凭据，只能 `POST /api/telemetry/`，不能读取资产或操作告警/工单。部署前运行 `python manage.py configure_ingest_principal`，并从密钥管理系统分别注入后端和网关的同一随机密钥。

> 示例阈值、模拟遥测和空间示意只用于教学答辩，不可直接用于真实管廊控制。
