# 软件使用手册

## 登录与账号申请

1. 前端的 API 地址由部署时的 `VITE_API_BASE_URL` 固定，页面不接受临时改写。
2. 使用管理员分配的账号和密码登录。Bearer Token 仅保存在当前标签页的 `sessionStorage`，关闭标签页后清除；仍应把前端部署在 HTTPS 下并防止 XSS。
3. 新用户只提交账号、姓名和角色，不提交密码。管理员批准后会生成一条 24 小时有效、仅显示一次的密码设置链接；设置成功后账号启用，链接立即失效。
4. 连接失败时检查 API 地址、`CORS_ALLOWED_ORIGINS`、账号状态以及 `/api/ready/`。

## 日常操作

1. 在告警中心确认事件并按需创建关联工单。
2. 在工单中心依次完成派发、处置、复核和关闭，禁止跳过受控状态。
3. 在资产台账按名称、区域和状态筛选；在数字孪生或 GIS 中定位资产。
4. 报表由服务端对完整数据库查询生成 CSV，不受前端当前分页限制；下载行为写入审计日志。
5. 管理员可在系统配置中维护阈值、账号审批和用户状态。

## 遥测接入

IoTDA 网关使用 `X-Ingest-Key` 机器凭据，只能 `POST /api/telemetry/`，不能读取资产或操作告警/工单。部署前运行 `python manage.py configure_ingest_principal`，并从密钥管理系统分别注入后端和网关的同一随机密钥。

> 示例阈值、模拟遥测和空间示意只用于教学答辩，不可直接用于真实管廊控制。
