# 软件使用手册

## 本地演示模式

1. 打开站点，顶部“数据”保持为“本地”。
2. 可切换管理员、运维员和查看者来演示权限差异；点击左下角重置可恢复演示数据。
3. 在告警中心确认事件，单独点击“关联工单”；再在工单中心派发、处置、复核和完成。
4. 在资产台账按名称、区域和状态筛选；在数字孪生中点击区域或资产定位。
5. 在数据洞察或各模块导出 CSV/JSON；在审计追踪中回看操作。

## API 模式

1. 顶部“数据”选择“API”。
2. 输入 API 地址、账号邮箱和密码，点击“连接并登录”。密码和令牌不会保存在浏览器存储中。
3. 连接成功后，角色来自 API；告警、工单、阈值、导出与审计由 PostgreSQL 持久化。
4. 点击“刷新数据”可立即从服务端回读。连接错误时检查 API 地址、`CORS_ALLOWED_ORIGINS`、账号状态和 `/api/ready/`。

> 演示阈值、模拟遥测和二维空间示意只用于教学答辩，不可直接用于真实管廊控制。
