# 答辩演示脚本（约 6 分钟）

> 2026-09-28 演示前核对：当前项目方验收覆盖 31 路已接入传感器，双 ESP 在线、V13 映射；L05 已拆除，气体读数按原始量/电压解释。使用 [当前状态](项目当前状态.md)指定的功能分支。可选 AI 演示：登录后打开右下角助手，询问页面操作；需要后端密钥和外网，助手不会读取实时遥测或执行设备控制。已有验收确认不替代演示当天设备在线检查。

1. **30 秒：范围** — 说明软件已预留真实硬件数据接口，本次演示不下发现场控制。
2. **60 秒：孪生与台账** — 加载实体 GLB，演示异常巡检、设备节点红色高亮、快速切换、模型映射清单和台账定位。
3. **90 秒：告警到工单** — 确认一条开放告警，建立来源工单，展示来源关联不可重复。
4. **90 秒：工单闭环** — 派发、开始处置、提交复核；切换管理员完成工单，展示告警恢复和资产状态回归。
5. **60 秒：治理** — 修改阈值、导出日报，在审计追踪中查到每一个关键操作。
6. **60 秒：企业化接入** — 说明短期 DRF Bearer Token、RBAC、PostgreSQL 事务、速率限制、健康/就绪检查、最小权限运行账号，以及仅限遥测 POST 的 IoTDA 机器 API Key。

备用方案：若正式 API 在演示中短时中断，页面保留最近一次只读数据快照并明确提示离线，恢复后使用顶部“重新连接”；若正式环境不可用，则启动本地 Django/SQLite 与 `seed_demo`，所有页面仍经 API 读写，且必须明确其不是正式 PostgreSQL 数据。
