# 答辩演示脚本（约 6 分钟）

1. **30 秒：范围** — 说明本期只演示软件业务闭环，不连接硬件或下发现场控制。
2. **60 秒：孪生与台账** — 在数字孪生点击 UT-ZB、设备和异常高亮，展示区域配置、资产坐标和台账筛选。
3. **90 秒：告警到工单** — 确认一条开放告警，建立来源工单，展示来源关联不可重复。
4. **90 秒：工单闭环** — 派发、开始处置、提交复核；切换管理员完成工单，展示告警恢复和资产状态回归。
5. **60 秒：治理** — 修改阈值、导出日报，在审计追踪中查到每一个关键操作。
6. **60 秒：企业化接入** — 切换 API 模式，说明 JWT、RBAC、PostgreSQL 事务、速率限制、健康检查、CI PostgreSQL 冒烟与最小权限运行账号。

备用方案：若 API 不可用，切回本地模式继续演示。页面会明确显示数据源，不能把本地数据误说成已持久化数据。
