# 答辩演示脚本（约 6 分钟）

1. **30 秒：范围** — 说明本期只演示软件业务闭环，不连接硬件或下发现场控制。
2. **60 秒：孪生与台账** — 在数字孪生点击 UT-ZB、设备和异常高亮，展示区域配置、资产坐标和台账筛选。
3. **90 秒：告警到工单** — 确认一条开放告警，建立来源工单，展示来源关联不可重复。
4. **90 秒：工单闭环** — 派发、开始处置、提交复核；切换管理员完成工单，展示告警恢复和资产状态回归。
5. **60 秒：治理** — 修改阈值、导出日报，在审计追踪中查到每一个关键操作。
6. **60 秒：企业化接入** — 说明短期 DRF Bearer Token、RBAC、PostgreSQL 事务、速率限制、健康/就绪检查、最小权限运行账号，以及仅限遥测 POST 的 IoTDA 机器 API Key。

备用方案：若正式 API 不可用，启动本地 Django/SQLite 与 `seed_demo` 后继续演示。所有页面仍经 API 读写，不能把本地开发数据库误说成正式 PostgreSQL 数据。
