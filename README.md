# 综合管廊数字孪生实体样品

本项目面向综合管廊实体样品的物联网感知、设备控制与三维数字孪生展示，目标是实现“真实采集、可控实体、三维映射、业务闭环”四项核心能力。

## 计划建设内容

- 综合管廊缩尺实体样品与多舱室结构
- STM32F103RCT6 传感采集与执行器控制
- MQTT 本地消息通信与设备状态反馈
- Three.js 三维数字孪生可视化
- 实时监测、告警、工单和历史数据查询
- 积水、烟雾/气体、门禁等情景联动

## 安全边界

本项目中的低成本烟雾、气体等教学传感模块只用于趋势采集和功能验证，不作为真实工程安全报警、联锁或人员进入许可的依据。实体样品采用低压供电，不引入明火、真实可燃气体或有毒介质。
