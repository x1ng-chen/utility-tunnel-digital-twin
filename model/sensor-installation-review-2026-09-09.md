# 传感器安装复核（2026-09-09）

阶段：结构验证。源文件为本地气泵修复候选 `air-pump-trial.blend`，本次检查不修改模型。整体未通过实体落地验收。

## 本轮要求与方法

逐项检查传感器本体、固定件、承载面，不以文字引线或线束接触冒充支撑；保留五个测点位置、主水路及气泵修复。使用世界坐标 BVH 表面接触、最近候选距离和局部渲染交叉核查。最近距离为顶点到表面的候选值，不是精确净空或安装公差。所有距离采用当前场景单位，不擅自换算为毫米。

## 发现

| 组别 | 几何证据 | 结论 |
|---|---|---|
| L01—L05 板卡 | 每块板卡均接触对应 `GEO-V09-L0x-BOARD-SUPPORT`；该支撑与对应竖支架接触 | 存在板卡支撑路径，不应因板后留空直接认定悬空 |
| L01—L05 探头 | 每个探头均接触对应 SERVICE-BOSS 和 PIPE_CLAMP；管夹与支架及相应水路连接 | 探头不是完全游离；螺纹、密封与维修净空仍未验收 |
| 氧气传感器 | 立柱和本体没有表面接触，且 Y 包围盒净间隔 0.00814655；本体与外透明壳发生表面穿插 | 明确装配缺陷。应整体重排氧气组并建立独立承载连接，不能把穿壳当固定 |
| 气体采样盒 | 与全部非注释网格均无表面接触；局部图可见游离于导轨上方 | 明确缺少安装支撑；同时需要核实采样管接入口，不宜只补一根柱子宣布完成 |
| 烟雾 / 甲烷 | 烟雾本体、底座与甲烷安装板/背板发生表面穿插；本体与自身底座无表面交线，最近候选距离约 0.00437 | 优先拆开装配组；单独检查烟雾底座，再避开甲烷面板及灯带 |
| 环境模块 | SHT30 与 PIPE-G01 相交；近景可见橙色管道遮挡/穿入模块下部 | 明确需调整安装净空；仅有接触不能证明合理安装 |
| CO 立柱 | 接触 CO 本体，但没有接触传感器导轨 | 承载路径不完整，须核查并补足导轨固定件 |

## 可落地要求仍缺的依据

当前 `model/README.md` 明确探头螺纹、安装孔、线长、泵口、软管和风机参数待实测，禁止凭 `_TEMP` 接口加工。仓库唯一 fabrication 制作包对应旧 V01，而非本轮候选；不能用其旧尺寸和旧节点映射验收当前模型。

实体落地尚需：现用实物尺寸与孔距、统一比例基准、独立支撑与检修净空、紧固和密封接口、线束应力释放、当前版本对应的物料/加工图与经批准的安全边界。当前仅是视觉与装配布局验证，不是加工许可或通电通水许可。

## 下一结构修复要求

1. 氧气组移离外壳穿插区，按本体—安装板—支架—导轨建立承载路径；保持传感器数量及资产编号。
2. 气体采样盒补独立可拆安装座，同时核对采样管接口。
3. 分离烟雾与甲烷安装组，调整环境模块与管道的干涉。
4. 对所有改动复查外壳、灯带、管路与导轨接触集合；渲染同视角前后图，重新导入 GLB 后再验收。
5. 结构稳定后再处理中文标签和全场网格清理。本轮没有上传或覆盖归档模型。
