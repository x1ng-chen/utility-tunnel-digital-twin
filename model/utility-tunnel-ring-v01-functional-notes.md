# 环形气体监测管廊模型：功能与制作说明

## 定位与边界

本模型是约 1 m 长的低压、低风险课堂/实习演示装置。气路仅适用于空气或经教师批准的安全模拟介质；不应用于可燃、有毒或缺氧气体的真实释放、储存或实验。

## 气路的工作方式

```text
安全空气/模拟气源
  → 左侧进气接头
  → 进气三通（G01 入口）
  → G01 环形主管的两条环向支路
  → 三处采样仓与传感器
  → 出气三通（G01 出口）
  → 流量控制件 / 风机侧
  → 右侧出气接头
```

G01 是一根闭合的环形主管，而不是两根断开的管。进气三通把气流送入环内，气体可沿环的两个方向扩散，并在出气三通处汇出。这样可以把不同传感点布置在不同的空间位置，便于演示多点响应、比较响应延迟和检查是否存在局部滞留。

若后续希望气体严格按一个方向依次通过所有检测点，应在实体版的入口/出口旁增加小型低压抽气泵或风机、限流孔板，并在不希望倒流的支路设置止回结构。该流量方案应由指导老师按实际器件和安全要求确认。

## 主要组件

| 组件 | 模型中的表现 | 功能 |
| --- | --- | --- |
| 透明外墙、内墙、顶板 | 环形透明亚克力罩 | 围成可观察的封闭空间，同时隔离内部管线；实体版建议使用 3–5 mm 亚克力及可拆的检修固定方式。 |
| G01 环形主管 | 橙色闭合管道 | 承担气体输送与多点分布。橙色用于将气路与蓝色水路区分。 |
| 进/出气接头 | 左侧进气、右侧出气外接件 | 连接安全模拟气源与排出/净化端；实体制作应使用可拆接头和密封垫。 |
| 进/出气三通 | 环管上的两个分流/汇流块 | 使外部进出气与闭合环路在机械关系上明确可见。 |
| 三个采样仓 | CH4、CO、O2 下方的短方仓、抱箍和彩色圈 | 作为传感器可拆装位置，便于更换、走线和让观众理解“传感器在管道哪个点采样”。 |
| CH4 / CO / O2 传感器 | 高、中、低三种高度的标识模块 | CH4 设在较高取样点、CO 居中、O2 较低；这是直观的教学分层，实际安装高度仍应服从具体传感器说明书与现场风险评估。 |
| 支撑立柱和底脚 | 环管下方的四组支撑 | 让管路有实体可制造的受力路径，不悬空。 |
| 阀门/流量控制件 | 右侧出气三通后的控制块与手柄 | 用于表示调流、检修隔离或与风机联动的位置。 |
| 水路与渗水区 | 蓝色管路、托盘和液位/湿度模块 | 与气路并列存在，用于演示渗水、液位和环境数据采集；不与 G01 气路混用。 |
| 控制与显示区 | 控制箱、指示灯、线槽 | 汇集传感器信号与供电；实体版宜采用低压供电、端子排、保险与应力释放。 |

## 本轮模型细化

1. 保留并验证了 G01 的闭合环形结构（76 个曲线点）。
2. 增加进气三通、出气三通、流量控制件和阀门手柄，明确“进—分流—环路—汇流—出”的流程。
3. 三个检测点均增加采样仓、抱箍、彩色识别环和支架；CH4、CO、O2 的高度分别设为高、中、低，视觉上更容易分辨。
4. 增加四处环管支撑及底脚，使后续根据模型制作时能明确管道的固定思路。
5. 保持透明亚克力外壳，以便从外部看见管路、传感器和控制部件。

## 实体制作前应确认

- 先使用空气、烟雾笔或其他经批准的无害介质联调；不要把该教学模型当作真实气体安全监测装置。
- 传感器的电压、预热时间、标定方式、交叉干扰和防护等级以实际器件数据表为准。
- 透明罩应留检修口，传感器、风机和接头应能从顶部或侧面拆下。
- 若要实现可靠定向流，先用实际风量与管径进行台架测试，再决定限流和止回件的尺寸。
