# OLED 与音频联合测试（2026-10-27）

用户已确认屏幕文字正常、状态会切换，唤醒后会自动回到待机。最终运行程序 SHA-256 与写入地址见 [OLED 构建报告](oled-build-report.json)，详细事件见 [实测 JSON](oled-test-report.json)。

- OLED：3V3 / GND、SDA GPIO41、SCL GPIO42，100kHz I²C，地址 0x3C。
- SSD1306-compatible 128×32 布局已能正常显示；ACK 和显示兼容性不能证明准确芯片型号，实际分辨率也未单独测量。
- 待机显示“离线待机 / 你好管廊”；BOOT 短按显示“播放测试 / 音量 20”；命中显示“唤醒成功 / 离线测试”，最终日志在 2150ms 后恢复待机。
- 初次显示测试观察到两次完整播放、一次后续唤醒；最终修正版本又观察到一次完整播放、一次播放后唤醒与自动恢复待机。两轮均有非零麦克风采样，未出现播放超时或致命异常。
- 离线模式仍不启动网络、ASR、Agent 或 TTS。无开机/唤醒自动播放，没有通过屏幕状态伪装联网问答。
- 探测不到 0x3C/0x3D 或面板初始化失败时，保留无屏音频模式；显示对象仅在 LVGL 就绪后发布。
- 限时提示使用的 FreeRTOS 返回值已按等待事件掩码处理，避免残留的播放完成事件阻止显示回到待机。

本轮仅写应用 0x20000，四个静态镜像摘要校验通过；既有 NVS 和运行时 otadata 保留。原始 Flash 与已验证的无屏音量20应用留在仓库外。早期 build-report.json 与固件包保持历史快照。
