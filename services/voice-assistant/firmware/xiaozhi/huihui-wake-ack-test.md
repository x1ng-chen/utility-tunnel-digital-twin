# 本地唤醒回应“我在”（2026-10-27）

当前固件已编译、烧录并通过四个静态镜像校验。运行日志确认回应已启用、音量为 40、OLED 初始化成功；用户已确认两次唤醒都听到“我在”，音量40合适；实物试听通过。串口监听窗口先于用户试听结束，窗口中没有新事件，不将人工反馈伪装成串口记录，也不把空窗口计为漏检。

- 说“你好管廊”后，在板端播放一次“我在”；屏幕同步显示“我在”，回应结束约两秒后回到待机。
- 开机、唤醒回应与 BOOT 测试的配置音量均为 40，运行音量上限 40；开机不自动播放声音。
- 回应期间暂停识别，排空播放队列后等待 300ms，关闭输出并重新启用检测，避免回答声进入唤醒识别。
- 同一事件快照出现唤醒与 BOOT 时优先回应一次唤醒；BOOT 仍使用原短提示音。
- 本机 Windows SAPI Huihui 合成“我在。”，无用户录音、无云合成调用。Ogg Opus 为单声道16kHz、22个60ms包，1.310秒有效音频；板端整包播放预计1.320秒。
- FFmpeg解码、Ogg CRC/EOS、原生Opus解码及本地ASR“我在”验证均已通过；这些不能代替喇叭实物试听。
